# Task VII — SQL Query Implementation for E-Commerce Database

## Objective
Implement SQL queries for retrieving, searching, filtering and reporting data in the E-Commerce Database.

## Requirements Covered

1. Perform **SELECT, WHERE, ORDER BY and DISTINCT** queries.
2. Search products based on **price, category and availability**.
3. Retrieve **customer and product information**.
4. Apply different **filtering conditions**.
5. Generate **basic business reports**.

## Database
- Database: `InventoryDB`
- Main tables used:
  - `Category`
  - `Product`
  - `Customer`
  - `Orders`
  - `Order_Details`

## Queries Included

### 1. Basic SQL Queries
- SELECT all products
- WHERE price filtering
- ORDER BY price
- DISTINCT category listing

### 2. Product Search
- Price range search
- Category-based search
- Available products
- Unavailable products

### 3. Customer and Product Information
- Customer details
- Customer order and purchased product details

### 4. Filtering Conditions
- Multiple conditions using AND
- Alternative conditions using OR

### 5. Business Reports
- Product count and average price by category
- Inventory availability summary
- Customer order and spending summary

## File
`Task-7-SQL-Query-Implementation.sql`

## Execution
Run the previous database setup tasks first, then execute the Task VII SQL file in MySQL Workbench or another MySQL-compatible environment.
